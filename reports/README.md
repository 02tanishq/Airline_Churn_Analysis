# Reports & Business Deliverables

This directory contains the executive and technical reports, business presentations, and generated figures for the Airline Loyalty Analytics project.

## Deliverables

| Deliverable | Format | Description |
| :--- | :--- | :--- |
| **[Airline Loyalty Analytics Technical Report](./Airline_Loyalty_Analytics_Technical_Report.pdf)** | PDF (7 Pages) | Comprehensive technical report detailing data preprocessing, RFM segmentation, XGBoost churn modeling, and prescriptive retention strategy. |
| **[Executive Summary](./Executive_Summary.md)** | Markdown | Executive-level summary outlining the business problem, methodology, findings, and strategic retention recommendations. |
| **[Figures & Visual Assets](./figures/)** | Directory (`.png`) | High-resolution (300 DPI) publication-quality charts and visual assets. |

## Generated Figures (`reports/figures/`)

- `feature_importance.png`: Relative importance of behavioral vs. demographic drivers of churn.
- `relative_segment_heatmap.png`: Normalized behavioral profiles across the 4 customer clusters (1.0 = average baseline).
- `segment_distribution.png`: Customer distribution across the behavioral segments.
- `retention_actions.png`: Prescriptive allocation of retention interventions across the cohort.
